Library Database Management System (DBMS)

This project is a Library Database Management System designed to efficiently manage library resources and staff using a relational database (SQL). 

Key features include:
Book Management: Add, update, delete, and search for books by title, author, id, or genre.
Member Management: Register and manage library members, including their personal details and membership status.
Staff Management: Maintain records of library staff, including their roles, contact information, and work schedules.
Search and Reporting: Enable searching for books and members, and generate reports on book inventory, member statistics, and staff details.

The system ensures data integrity through a well-designed schema with tables for books, members, and staff, linked via appropriate foreign keys. It aims to streamline library operations by organizing data, improving accessibility, and supporting staff management.
Clone the repository: git clone https://github.com/abdelrhman-22/Library_DBMS.git
Set up your database (e.g., MySQL) and update connection settings.
Run the SQL scripts to create tables for books, members, and staff.
Use the provided scripts to manage the library data.
Technologies

Language: SQL (additional scripting may use Python or other languages)
