Library Database Management System (DBMS)
A simple system to manage library resources using a relational database (e.g., MySQL).

Features
Book Management: Add, update, delete, and search books by title, author, ISBN, or genre.
Member Management: Register and manage members with their details and status.
Staff Management: Track staff roles, contacts, and schedules.
Search & Reporting: Search books/members and generate reports on inventory, members, and staff.
Setup
Clone the repository: git clone https://github.com/abdelrhman-22/Library_DBMS.git
Set up your database (e.g., MySQL) and update connection settings.
Run the SQL scripts to create tables for books, members, and staff.
Use the provided scripts to manage the library data.
Technologies
Database: MySQL (or any relational DBMS)
Language: SQL (additional scripting may use Python or other languages)
